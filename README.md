# AI Limit Monitor

Уведомление в тот момент, когда лимиты **Codex CLI** или **Claude Code** снова доступны.

Программа не запускает ни `codex`, ни `claude` и не ходит в сеть — она читает файлы,
которые эти инструменты пишут сами. Проверка занимает доли секунды и не стоит ни одного токена.

```
┌────────────────────────────────────┐   ┌────────────────────────────────────┐
│ AI LIMIT MONITOR                   │   │ AI LIMIT MONITOR                   │
│ Codex доступен! 🟢                 │   │ Claude доступен! 🟣                │
│ Лимиты восстановлены.              │   │ Лимиты восстановлены.              │
│ 5ч 4%, окно до 09:12               │   │ 5ч 12%, окно до 09:30              │
│                            [ OK ]  │   │                            [ OK ]  │
└────────────────────────────────────┘   └────────────────────────────────────┘
```

Уведомление приходит в пределах трёх минут после сброса окна и висит, пока его не закроют.
Пока вы ни разу не упирались в лимит, программа молчит — она реагирует на переход
«исчерпано → доступно», а не на факт «сейчас всё хорошо».

Только Windows 10 / 11.

---

## Чего программа НЕ делает

Весь код — в одном файле `AI-Limit-Monitor.ps1`, его можно прочитать перед установкой.

| | |
|---|---|
| Сетевые запросы | нет ни одного — поищите в коде `Invoke-WebRequest`, `Invoke-RestMethod`, `http` |
| Права администратора | не требуются и не запрашиваются |
| Запуск `codex` / `claude` | нет — ваши лимиты не расходуются |
| Телеметрия, сбор данных | нет |
| Изменения вне вашего профиля | нет — полный список ниже |

## Что нужно, чтобы работало

Программа следит за двумя инструментами независимо. Можно подключить оба, можно любой один —
второй просто будет показан как «нет данных».

**Для Codex.** Свежий Codex CLI: `npm install -g @openai/codex@latest`. И нужно хотя бы раз
поработать в нём обычным способом — запустить `codex`, что-нибудь спросить. Цифры лимитов
Codex записывает на диск именно во время такой работы, из ниоткуда они не появятся.

**Для Claude Code.** Подписка Pro или Max (на API-ключе Anthropic цифры лимитов не отдаёт).
Плюс один шаг после установки — см. ниже.

## Установка

### Вариант A — двойной клик

1. Скачайте `AI-Limit-Monitor.ps1` и `install.bat` **в одну папку**.
2. Двойной клик по `install.bat`.
3. Если появится синее окно SmartScreen — «Подробнее» → «Выполнить в любом случае».

Папка любая, хоть «Загрузки». Единственное: не переносите её потом в другое место —
автозапуск ссылается на этот путь и после переноса перестанет работать. Если всё-таки
перенесли, просто запустите `install.bat` заново.

Батник — двенадцать строк, вот он целиком:

```bat
@echo off
title AI Limit Monitor - install
set "PS=%SystemRoot%\System32\WindowsPowerShell\v1.0\powershell.exe"
if not exist "%~dp0AI-Limit-Monitor.ps1" (
  echo AI-Limit-Monitor.ps1 not found next to this file.
  pause
  exit /b 1
)
"%PS%" -NoProfile -ExecutionPolicy Bypass -Command "Unblock-File -LiteralPath '%~dp0AI-Limit-Monitor.ps1' -ErrorAction SilentlyContinue"
"%PS%" -NoProfile -ExecutionPolicy Bypass -File "%~dp0AI-Limit-Monitor.ps1" -Setup
echo.
pause
```

Он делает ровно две вещи: снимает с `.ps1` метку «файл скачан из интернета» и запускает
этот же `.ps1`. Ничего своего не устанавливает и никуда не обращается.

### Вариант B — из PowerShell, без батника

**Как открыть PowerShell.** Нажмите <kbd>Win</kbd>, наберите `powershell`, нажмите <kbd>Enter</kbd>.
Пункт «Запуск от имени администратора» выбирать не нужно — наоборот, обычное окно подходит лучше.

Дальше по одной команде за раз. Первая — переход в папку со скриптом, путь подставьте свой:

```powershell
cd C:\Tools\ai-limit-monitor
```

Вторая — снять с файла метку «скачан из интернета»:

```powershell
Unblock-File .\AI-Limit-Monitor.ps1
```

Третья — собственно установка. Длинная, копируйте целиком одной строкой:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\AI-Limit-Monitor.ps1 -Setup
```

Она проведёт четыре шага в одном окне: зарегистрирует источник уведомлений, покажет тестовое
уведомление, подключит Claude Code и добавит программу в автозапуск.

> **Важно:** на шаге с тестовым уведомлением в правом нижнем углу должно всплыть окошко.
> Если его нет — дальше идти нет смысла, программа будет работать вхолостую.
> Что делать — в разделе «Если что-то пошло не так».

### Последний шаг — для Claude Code

Закройте все открытые окна `claude`, откройте заново и задайте любой вопрос. Цифры лимитов
Claude Code сообщает только после первого ответа модели, а настройки читает при старте сессии —
поэтому нужен именно новый запуск. Затем проверьте, что данные дошли:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\AI-Limit-Monitor.ps1 -CheckStatusline
```

Команда разложит по пунктам, на каком шаге всё остановилось, если что-то не сработало.

Для Codex ничего дополнительно делать не нужно.

## Что программа меняет в системе

Всё — в пределах вашего пользовательского профиля:

| путь | зачем |
|---|---|
| `%LOCALAPPDATA%\AILimitMonitor\` | журнал работы и служебные файлы |
| `HKCU:\SOFTWARE\Classes\AppUserModelId\AI.Limit.Monitor` | без этой записи Windows молча не показывает уведомление |
| `shell:startup\AI Limit Monitor.lnk` | автозапуск при входе в систему |
| `%USERPROFILE%\.claude\settings.json` | строка состояния Claude Code; рядом кладётся копия `settings.json.bak-<дата>` |

## Удаление

Двойной клик по `uninstall.bat`. Он уберёт программу из автозапуска и вернёт настройки
Claude Code как были. Папку `%LOCALAPPDATA%\AILimitMonitor` можно удалить руками.

## Если что-то пошло не так

**«Не удается загрузить файл … не имеет цифровой подписи»**

Windows по умолчанию запрещает запускать скачанные скрипты. Чинить ничего не надо: во всех
командах выше уже стоит `-ExecutionPolicy Bypass` — он разрешает запуск конкретно этого файла
и ничего в системе не меняет. Ошибка появляется, если запустить скрипт без этого ключа.

**Тестовое уведомление не появилось**

* Выключите «Фокусировку внимания» / «Не беспокоить» — в этом режиме уведомления уходят сразу
  в Центр уведомлений (<kbd>Win</kbd>+<kbd>N</kbd>), минуя экран. Загляните туда: если сообщение
  там есть, всё работает.
* Проверьте, что уведомления разрешены: Параметры → Система → Уведомления.
* Не запускайте программу от администратора — оттуда уведомления доходят хуже.

**Claude: «нет данных»**

Перехватчик ещё ни разу не отработал. Закройте все окна `claude`, откройте заново, задайте
вопрос — и запустите `-CheckStatusline`, он покажет, где именно обрыв.

**Codex: «нет данных»**

Либо старая версия CLI — обновите: `npm install -g @openai/codex@latest`. Либо вы ещё не
работали в `codex` после установки — запустите его и что-нибудь спросите.

**Уведомление не пришло, хотя лимит сбрасывался**

Посмотрите журнал, там видно, что программа видела в этот момент:

```powershell
Get-Content "$env:LOCALAPPDATA\AILimitMonitor\monitor.log" -Tail 20
```
